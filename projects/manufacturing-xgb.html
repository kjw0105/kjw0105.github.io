공작기계 진동 데이터 기반 이상 상태 분류

불균형 진동 데이터에서 전체 정확도보다 실제 NG를 놓치지 않는 것을 우선해 평가 기준과 분류 임계값을 설계한 프로젝트.

2026XGBoost특징 설계임계값 분석
문제
적은 NG와 높은 False Negative 위험
접근
NG Recall 중심 평가와 임계값 조정
담당
데이터 구조화·모델링·평가

문제와 중요성

OK 191건에 비해 NG는 53건으로 적었습니다. 이런 불균형 데이터에서는 전체 정확도가 높아도 실제 이상을 정상으로 판단하는 False Negative가 남을 수 있습니다.

핵심 질문

전체 정확도가 아니라 실제 NG를 놓치지 않는 모델을 만들려면 어떤 평가 기준을 사용해야 할까?

해결 접근

오분류의 비용이 같지 않다고 판단했습니다. NG 누락 위험을 먼저 정의하고, 진동 특징과 XGBoost 모델을 구성한 뒤 NG Recall과 Precision의 균형을 기준으로 임계값을 선택했습니다.

판단과 실행 과정

01 · 위험 정의

False Negative를 더 중요한 오류로 봤습니다.

실제 NG를 OK로 판단하면 이상 상태를 놓치므로 Accuracy보다 NG Recall을 우선했습니다.

02 · 모델 선택

설계한 진동 특징을 XGBoost로 분류했습니다.

비선형 관계를 학습하는 모델을 구성하고 Recall, Precision, F1, F2, PR-AUC, ROC-AUC를 함께 확인했습니다.

03 · 임계값 결정

Recall만 높이는 대신 Precision과의 균형을 확인했습니다.

NG를 더 많이 탐지하면서 오탐 증가를 함께 비교해 최종 임계값 0.17을 적용했습니다.

직접 기여

프로젝트 전체 범위

원시 진동 데이터를 구조화하고 특징 기반 XGBoost 분류와 임계값 평가를 수행했습니다.

데이터 구조화, 특징 설계와 모델링, NG 중심 평가를 직접 담당했습니다.

01 · 데이터

244개 RAW 파일의 진동 데이터를 OK·NG 기준으로 구조화했습니다.

02 · 모델링

진동 특징을 설계하고 XGBoost 분류 모델을 구성했습니다.

03 · 평가

NG Recall을 중심으로 여러 지표와 임계값을 비교해 0.17을 선택했습니다.
