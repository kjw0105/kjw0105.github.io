문제

OK 191건, NG 53건의 불균형 데이터에서는 정확도가 높아도 False Negative가 남을 수 있었습니다.

핵심 질문

실제 NG를 놓치지 않으려면 어떤 평가 기준을 사용해야 할까?

접근과 판단

NG 누락 위험이 더 크다고 보고 Accuracy보다 NG Recall을 우선했습니다. Precision 변화와 함께 임계값을 조정했습니다.

모델 선택

설계한 진동 특징의 비선형 관계를 XGBoost로 분류했습니다.

Recall, Precision, F1, F2, PR-AUC와 ROC-AUC를 함께 확인했습니다.

임계값 결정

NG 탐지 증가와 오탐 변화를 함께 비교했습니다.

Recall과 Precision의 균형을 기준으로 최종 임계값 0.17을 선택했습니다.

직접 기여

프로젝트 전체 범위

팀은 전체 분류 파이프라인을 구성했습니다.

데이터·특징·모델링과 NG 중심 평가를 직접 담당했습니다.

01 · 데이터

244개 RAW 파일의 진동 데이터를 OK·NG 기준으로 구조화했습니다.

02 · 모델링

진동 특징을 설계하고 XGBoost 분류 모델을 구성했습니다.

03 · 평가

NG Recall을 중심으로 여러 지표와 임계값을 비교해 0.17을 선택했습니다.
