RO Membrane CIP Optimization

RO membrane 운영 데이터를 분석해 막 성능 저하 비용과 세척 비용의 균형을 고려한 CIP 일정 최적화 시나리오를 도출했습니다.

Background & Problem

RO 공정에서 세척이 잦으면 약품비와 가동 중단이 늘고, 늦으면 막 성능 저하 손실이 커집니다. 실제 데이터에서는 세척 기준도 운전 사이클마다 달라 데이터 기반으로 적절한 시점을 판단할 필요가 있었습니다.

핵심 질문

막 성능 저하와 세척 비용 사이의 균형을 어떻게 운영 일정으로 바꿀 것인가?

Approach

예측 결과를 운영 판단으로 연결하기 위해 공정 분석 결과를 비용 목적함수로 정식화했습니다.

데이터 퍼듀대학교 여름 프로그램 팀 프로젝트에서 분석 자료로 활용한 K-water RO 공정 데이터

데이터 품질

센서 이상과 세척 구간을 구분했습니다.

24시간 Rolling Z-score로 스파이크를 처리하고 운전 사이클 내부만 보간한 뒤 is_operating을 추가했습니다.

모델 비교

복잡도보다 제한된 데이터에서의 안정성을 봤습니다.

자기회귀 특성을 고려해 Ridge와 LSTM 결과를 비교했습니다.

최적화

막 성능 저하 손실과 세척 비용을 함께 반영했습니다.

비용 목적함수를 기준으로 Greedy와 Tabu Search 시나리오를 비교했습니다.

My Role

팀 프로젝트 범위

팀은 전처리, 모델 비교, 비용 목적함수와 CIP 일정 탐색을 수행했습니다.

01 · 문제 정의

Introduction과 Motivation을 구성하고 비플럭스 감소와 CIP 비용의 상충관계를 최적화 문제로 정리했습니다.

02 · 데이터

Problem Formulation과 Dataset을 맡아 공정변수, 운전·세척 구간과 분석 범위를 설명했습니다.

03 · 결과 해석

모델과 최적화 결과를 데이터 규모, 자기회귀 특성, 비용 균형의 관점에서 해석했습니다.

04 · 커뮤니케이션

프로젝트 결과를 12분 영어 발표로 전달했습니다.

Verification Scope — 실제 현장 배포 결과가 아니라, 여름 프로그램에서 제공된 운영 데이터 기반 최적화 시나리오입니다. K-water와 직접 협업하거나 현장에 적용한 프로젝트로 표현하지 않습니다.
