RO 비플럭스 분석 및 CIP 일정 최적화

공정 데이터 분석 결과를 막 성능 저하 비용과 세척 비용 사이의 균형을 찾는 CIP 운영 의사결정으로 연결한 프로젝트.

문제와 중요성

CIP를 자주 하면 막 성능을 회복할 수 있지만 약품비와 가동 중단 비용이 늘고, 늦추면 생산 성능 저하 손실이 커집니다. 실제 데이터의 세척 기준도 모든 운전 사이클에 동일하지 않았습니다.

핵심 질문

공정 데이터를 분석하는 데서 끝나지 않고, 실제 CIP 시점 결정으로 연결하려면 어떻게 해야 할까?

해결 접근

먼저 데이터 품질과 운전 상태를 구분하고 막 성능 변화를 해석했습니다. 이후 예측 결과를 막 성능 저하 비용과 세척 비용의 목적함수로 바꿔 CIP 일정을 탐색했습니다.

판단과 실행 과정

01 · 데이터 품질

센서 이상과 실제 세척 구간을 같은 결측값으로 처리하지 않았습니다.

24시간 Rolling Z-score로 비플럭스·운영차압·유입압력 스파이크를 처리하고, 0값과 변수별 결측치를 구분해 보간했습니다. 운전 사이클 내부만 보간하고 is_operating을 추가했습니다.

02 · 모델 비교

복잡한 모델보다 데이터 특성에 맞는 안정성을 봤습니다.

Ridge와 LSTM을 비교했고, 제한된 데이터 규모와 자기회귀 특성에서 Ridge가 더 안정적인 결과를 보인 것으로 해석했습니다.

03 · 운영 결정

예측값을 비용과 제약조건으로 전환했습니다.

막 성능 저하 손실과 CIP 비용을 목적함수로 구성하고 λ에 따른 균형을 확인하며 그리디 탐색과 타부 탐색을 비교했습니다.

직접 기여

팀 프로젝트 범위

K-water 공정 데이터 전처리, 모델 비교, 비용 목적함수와 CIP 일정 탐색을 수행했습니다.

제가 직접 담당한 부분은 다음과 같습니다.

01 · 문제 정의

비플럭스 감소와 CIP 비용의 상충관계를 운영 최적화 문제로 정리했습니다.

02 · 데이터 분석

주요 공정변수를 검토하고 운전 구간과 세척 구간을 구분하는 분석 과정에 참여했습니다.

03 · 결과 해석

Ridge와 LSTM 결과를 데이터 규모와 자기회귀 특성 관점에서 비교하고 CIP 의사결정과 연결했습니다.

04 · 결과물

영문 발표자료와 질의응답 내용을 검토하고, 최종 프로젝트 자료의 취합과 제출을 맡았습니다.
