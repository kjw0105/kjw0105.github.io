문제

CIP가 잦으면 비용과 가동 중단이 늘고, 늦으면 막 성능 저하 손실이 커집니다. 세척 기준도 운전 사이클마다 달라 적절한 시점을 판단하기 어려웠습니다.

핵심 질문

공정 분석을 CIP 시점에 관한 최적화 제안으로 어떻게 연결할 것인가?

접근과 판단

예측만으로 세척 시점을 정할 수 없어, 운전 상태 분석 결과를 막 성능 저하·세척 비용의 목적함수로 정식화했습니다.

데이터 출처 퍼듀대학교 여름 프로그램 팀 프로젝트에서 K-water RO 공정 데이터를 분석 자료로 활용했습니다.

모델 비교

모델 복잡도보다 안정성을 봤습니다.

제한된 데이터와 자기회귀 특성에서 Ridge가 LSTM보다 안정적이었습니다.

최적화 기준

예측 결과를 비용 목적함수로 정식화했습니다.

막 성능 저하 손실과 CIP 비용의 균형을 목적함수로 구성하고 그리디·타부 탐색을 비교했습니다.

분석 변수 비플럭스 · 운영차압 · 유입압력 · 생산량 · TDS · 수온 · 탁도 · 전도도 · pH · 강수량 · 기온

직접 기여

팀 프로젝트 범위

팀은 전처리, 모델 비교, 비용 목적함수와 CIP 일정 탐색을 수행했습니다.

제가 직접 담당한 부분은 다음과 같습니다.

01 · 문제 정의

비플럭스 감소와 CIP 비용의 상충관계를 최적화 문제로 정리했습니다.

02 · 데이터 분석

공정변수를 검토하고 운전·세척 구간을 구분했습니다.

03 · 결과 해석

Ridge와 LSTM을 데이터 규모·자기회귀 특성 관점에서 비교해 최적화 시나리오를 해석했습니다.

04 · 결과물
