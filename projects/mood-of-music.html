Mood of Music

음악을 검색하고 감상하며, 3–5곡으로 개인의 취향 카드를 만들고 저장·공유하는 웹 경험을 구현한 개인 프로젝트입니다.

Overview

좋아하는 음악을 단순히 목록으로 저장하는 대신, 분위기와 장르, 대표 곡을 하나의 시각적인 카드로 정리하고 다른 사람의 취향도 탐색할 수 있게 만들었습니다.

핵심 질문

음악 취향을 검색·감상·표현·공유까지 이어지는 하나의 경험으로 만들 수 있을까?

Problem & Approach

기능이 분리된 음악 앱 흐름을 한 화면 안에서 자연스럽게 이어지도록 설계했습니다.

01곡 검색
0230초 미리듣기
033–5곡 선택
04취향 카드 생성
05저장·공유
검색과 재생

iTunes Search API 결과를 실제 감상 흐름으로 연결했습니다.

곡명·아티스트 검색, 앨범 커버, 미리듣기 재생과 큐 표시를 구현했습니다.

취향 표현

분위기·장르·대표 곡을 카드 구성 요소로 만들었습니다.

사용자가 3–5곡을 선택하고 카드 이름과 분위기, 최대 3개의 장르를 조합할 수 있습니다.

상호작용

카드와 곡에 반응을 남길 수 있도록 했습니다.

Firestore를 이용한 카드 저장과 공유 링크, 곡별 별점·댓글 기능을 구현했습니다.

My Role

개인 프로젝트로 정보 구조, 비주얼 콘셉트, 반응형 레이아웃과 기능 구현을 모두 진행했습니다.

01 · EXPERIENCE

공연장과 바이닐을 모티프로 탐색·재생·카드 제작 흐름을 한 페이지에 설계했습니다.

02 · FRONTEND

Vanilla JavaScript로 검색, 오디오 재생, 큐, 모달 폼과 카드 렌더링 상태를 관리했습니다.

03 · DATA

Firebase Firestore를 연결해 사용자 카드와 곡별 반응 데이터를 저장하도록 구성했습니다.

04 · RESPONSIVE

데스크톱 3열 라운지를 모바일 1열 흐름으로 바꾸고 카드·모달을 작은 화면에 맞췄습니다.

Result

검색 → 미리듣기 → 취향 카드 → 공유로 이어지는 동작 가능한 프로토타입
